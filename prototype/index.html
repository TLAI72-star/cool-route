How CoolRoute v2 works

v2 fixes the four v1 failures from the architecture doc: identical routes → weather/time-aware edge costs; no live weather → HKO dual-source; no day/night → browser clock + sun position; straight-line artefacts → graph routing only, no straight-line fallback.

Edge cost (build guide Step 6)

cost = length × (1 + heat + sun − cool_bonus)
heat = max(0, temp°C − 26) × 0.5 (daytime only)
sun = (1 − shade) × max(0, sun_elevation) × 0.05
cool_bonus = 1 if a cooling point is within 200 m

Binary shade from real buildings

2,322 real building footprints + heights (OpenStreetMap via Overpass). A segment is shaded (1) when any building stands between it and the sun — bearing within ±45° of the sun azimuth and within the building's shadow length height / tan(elevation) — or when the path is covered (escalator / subway / walkway, detected from OSM names). Otherwise sunny (0). v2 deliberately uses 0/1 shade; fine-grained PET/UTCI is v3+.

Routing (graph only)

Real pedestrian geometry from an OSRM foot-profile demo server (OSM data): direct query with alternatives plus shade-corridor waypoint variants, deduplicated, then scored per ~30 m segment. If A or B falls outside Hong Kong coverage (lat 22.1–22.6, lon 113.8–114.5) the app returns a 422-style error — never a straight line. Production path: self-hosted Valhalla / LandsD 3D pedestrian network.

Weather & time

  • Weather: HKO current weather (data.weather.gov.hk, no key) → Open-Meteo fallback (“↻ 備份源”) → last-good snapshot with stale warning. “更新於” shows data time; over 30 min is highlighted.
  • Time: browser clock in HKT + NOAA/pvlib-equivalent sun position; day / civil-twilight / night shown in the badge and as a map tint.
  • Routes: Fastest = min walking time · Coolest = min heat cost · Balanced = time × (1 + λ·heat penalty), λ from heat sensitivity.

Data sources & licences

  • Routing: OSRM foot demo server, OSM data (ODbL, fair-use demo) → Valhalla self-host / LandsD API.
  • Buildings: OpenStreetMap via Overpass (ODbL) → LandsD/CSDI 3D Spatial Data (free key on request).
  • Weather: HKO open data (data.gov.hk terms) + Open-Meteo (free non-commercial tier).
  • Basemap: CARTO Voyager (© OpenStreetMap contributors, © CARTO). No Mapbox tokens anywhere.

Designed failure modes

HKO down → Open-Meteo badge. All weather down → stale snapshot + yellow warning. A/B outside coverage → red 422 toast. 3D layer fails (or mobile) → automatic 2D degrade. Coolest = Fastest → amber warning suggesting a different departure time.
